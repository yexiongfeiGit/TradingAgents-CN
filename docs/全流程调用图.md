# 股票代码到决策输出的全流程调用图

## 系统总览

TradingAgents-CN系统采用多智能体协作架构，从用户输入股票代码到输出最终投资决策，经过以下主要阶段：

```mermaid
graph TD
    A[用户输入] --> B[main.py入口]
    B --> C[TradingAgentsGraph.propagate方法]
    C --> D[状态初始化]
    D --> E[分析师团队并行分析]
    E --> F[研究团队辩论]
    F --> G[研究经理综合决策]
    G --> H[交易员制定投资计划]
    H --> I[风险管理团队评估]
    I --> J[最终投资决策]
    J --> K[输出结果]
```

## 错误处理机制

### 重试机制
```python
# 工具调用失败重试
for attempt in range(max_retries):
    try:
        result = tool_function(**params)
        break
    except Exception as e:
        if attempt == max_retries - 1:
            raise e
        time.sleep(retry_delay)
```

### 降级处理
- LLM调用失败时切换到备用模型
- 工具调用失败时返回默认值
- 网络超时时使用缓存数据
