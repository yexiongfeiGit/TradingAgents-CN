## 详细流程分解

### 1. 初始化阶段

```mermaid
sequenceDiagram
    participant User
    participant TAG as TradingAgentsGraph
    participant LLM as LLM Factory
    participant Memory as Memory System
    
    User->>TAG: 输入股票代码
    TAG->>TAG: 解析输入参数
    TAG->>LLM: create_llm_by_provider()
    LLM-->>TAG: LLM实例
    TAG->>Memory: 初始化内存系统
    Memory-->>TAG: 内存管理器
    TAG->>User: 系统初始化完成
```

### 2. 数据获取与分析阶段

```mermaid
sequenceDiagram
    participant Graph as TradingGraph
    participant SMA as SocialMediaAnalyst
    participant FA as FundamentalsAnalyst
    participant MA as MarketAnalyst
    participant NA as NewsAnalyst
    participant CA as ChinaAnalyst
    
    Graph->>SMA: 启动社交媒体分析
    Graph->>FA: 启动基本面分析
    Graph->>MA: 启动市场分析
    Graph->>NA: 启动新闻分析
    Graph->>CA: 启动中国市场分析
    
    par 并行执行
        SMA->>SMA: get_chinese_social_sentiment()
        SMA-->>Graph: 情绪分析报告
    and
        FA->>FA: get_stock_fundamentals()
        FA-->>Graph: 基本面分析报告
    and
        MA->>MA: get_stock_market_data()
        MA-->>Graph: 技术分析报告
    and
        NA->>NA: get_finnhub_news()
        NA-->>Graph: 新闻分析报告
    and
        CA->>CA: get_china_market_data()
        CA-->>Graph: 中国市场报告
    end
```

### 3. 研究团队辩论阶段

```mermaid
sequenceDiagram
    participant Graph
    participant Bull as BullResearcher
    participant Bear as BearResearcher
    participant RM as ResearchManager
    
    Graph->>Bull: 传递所有分析报告
    Graph->>Bear: 传递所有分析报告
    
    Bull->>Bull: 分析看涨理由
    Bull-->>Graph: 看涨观点
    
    Bear->>Bear: 分析看跌理由
    Bear-->>Graph: 看跌观点
    
    Graph->>RM: 启动辩论管理
    RM->>RM: 综合多空观点
    RM->>RM: 制定投资计划
    RM-->>Graph: 投资建议
```

### 4. 风险管理评估阶段

```mermaid
sequenceDiagram
    participant Graph
    participant Agg as AggressiveDebator
    participant Con as ConservativeDebator
    participant Neu as NeutralDebator
    participant RiskM as RiskManager
    
    Graph->>Agg: 投资计划 + 分析报告
    Graph->>Con: 投资计划 + 分析报告
    Graph->>Neu: 投资计划 + 分析报告
    
    Agg->>Agg: 激进风险评估
    Agg-->>Graph: 激进观点
    
    Con->>Con: 保守风险评估
    Con-->>Graph: 保守观点
    
    Neu->>Neu: 中性风险评估
    Neu-->>Graph: 中性观点
    
    Graph->>RiskM: 三方观点汇总
    RiskM->>RiskM: 综合风险评估
    RiskM-->>Graph: 风险控制建议
```

### 5. 最终交易决策阶段

```mermaid
sequenceDiagram
    participant Graph
    participant Trader
    participant Memory
    
    Graph->>Trader: 所有分析报告 + 投资建议 + 风险评估
    
    Trader->>Memory: 检索历史记忆
    Memory-->>Trader: 相似交易经验
    
    Trader->>Trader: 识别股票类型
    Trader->>Trader: 适配货币单位
    Trader->>Trader: 综合分析所有信息
    Trader->>Trader: 生成投资建议
    
    Trader-->>Graph: 最终交易决策
```

## 错误处理流程

### 异常捕获机制

```mermaid
graph TD
    A[智能体执行] --> B{是否异常?}
    B -->|是| C[异常捕获]
    B -->|否| D[正常执行]
    
    C --> E[记录错误日志]
    E --> F[分析错误类型]
    
    F --> G{可重试错误?}
    G -->|是| H[指数退避重试]
    G -->|否| I[降级处理]
    
    H --> J{重试成功?}
    J -->|是| D
    J -->|否| I
    
    I --> K[使用默认响应]
    K --> L[标记异常状态]
    L --> M[继续执行流程]
    
    D --> M
```

### 降级策略

```mermaid
graph TD
    A[主数据源失败] --> B[切换到备用源]
    B --> C{备用源可用?}
    C -->|是| D[使用备用数据]
    C -->|否| E[使用缓存数据]
    
    E --> F{缓存数据有效?}
    F -->|是| G[返回缓存结果]
    F -->|否| H[生成默认响应]
    
    D --> I[标记数据源问题]
    G --> I
    H --> I
```
