# TradingAgents-CN 配置和使用指南

## 概述

TradingAgents-CN 是一个基于多智能体的量化交易系统，提供股票数据获取、技术分析、策略回测和自动交易功能。本指南将帮助您快速配置和使用系统。

## 系统架构

### 核心模块

1. **数据流模块 (dataflows)**
   - 股票数据获取
   - 新闻数据聚合
   - 技术指标计算
   - 数据标准化处理

2. **智能体模块 (agents)**
   - 交易决策智能体
   - 风险管理智能体
   - 组合管理智能体
   - 市场分析智能体

3. **策略模块 (strategies)**
   - 技术分析策略
   - 基本面分析策略
   - 量化交易策略
   - 机器学习策略

4. **回测模块 (backtesting)**
   - 历史数据回测
   - 策略性能评估
   - 风险指标计算
   - 收益分析

## 环境配置

### 系统要求

- Python 3.8+
- 8GB+ RAM (推荐16GB)
- 10GB+ 可用磁盘空间
- 稳定的网络连接

### 5. 智能体交易

```python
from tradingagents.agents.trading_agent import TradingAgent
from tradingagents.agents.risk_manager import RiskManager

# 创建交易智能体
agent = TradingAgent(
    name="AI_Trader_001",
    initial_capital=100000,
    risk_tolerance="medium"
)

# 创建风险管理器
risk_manager = RiskManager(
    max_position_size=0.1,
    stop_loss_threshold=0.05,
    take_profit_threshold=0.15
)

# 执行交易决策
async def execute_trading():
    # 分析市场
    market_analysis = await agent.analyze_market("000001")
    
    # 生成交易信号
    signal = await agent.generate_signal(market_analysis)
    
    # 风险评估
    risk_assessment = risk_manager.assess_risk(signal)
    
    if risk_assessment['approved']:
        # 执行交易
        order = await agent.execute_order(
            symbol="000001",
            side=signal['side'],
            quantity=signal['quantity'],
            price=signal['price']
        )
        print(f"执行交易: {order}")
    else:
        print(f"交易被拒绝: {risk_assessment['reason']}")

# 运行
asyncio.run(execute_trading())
```

### 3. 自定义智能体

```python
from tradingagents.agents.base_agent import BaseAgent

class CustomAgent(BaseAgent):
    def __init__(self, config):
        super().__init__(config)
        self.custom_model = self.load_custom_model()
        
    async def analyze_market(self, symbol):
        # 自定义市场分析
        data = await self.get_market_data(symbol)
        analysis = self.custom_model.predict(data)
        return analysis
        
    async def generate_signal(self, analysis):
        # 自定义信号生成
        if analysis['score'] > 0.7:
            return {'action': 'BUY', 'confidence': analysis['score']}
        elif analysis['score'] < 0.3:
            return {'action': 'SELL', 'confidence': 1 - analysis['score']}
        else:
            return {'action': 'HOLD', 'confidence': 0.5}

# 注册自定义智能体
from tradingagents.agents import register_agent
register_agent('custom', CustomAgent)
```

**问题**: 无法获取股票数据
**解决方案**:
- 检查网络连接
- 验证API密钥配置
- 检查数据源状态
- 查看错误日志


#### 2. 内存不足

**问题**: 系统内存不足

#### 3. 性能问题

**问题**: 系统运行缓慢
**解决方案**:
- 启用数据缓存
- 优化数据库查询
- 使用异步处理
- 减少不必要的计算


### 2. 错误处理

```python
from tradingagents.utils.error_handler import ErrorHandler

# 创建错误处理器
error_handler = ErrorHandler()

# 使用装饰器进行错误处理
@error_handler.handle_errors
async def risky_operation():
    # 可能出错的操作
    result = await some_risky_operation()
    return result

# 手动错误处理
try:
    result = await risky_operation()
except DataError as e:
    logger.error(f"数据错误: {e}")
    # 使用备用数据源
    result = await backup_operation()
except NetworkError as e:
    logger.error(f"网络错误: {e}")
    # 重试操作
    result = await retry_operation()
except Exception as e:
    logger.error(f"未知错误: {e}")
    # 记录错误并继续
    error_handler.log_error(e)
    result = None
```
