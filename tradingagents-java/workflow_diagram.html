🔧 工作流引擎核心机制

sequenceDiagram participant Client as 客户端 participant Engine as WorkflowEngine participant Step as WorkflowStep participant Agent as BaseAgent participant State as AgentState Client->>Engine: 创建工作流 Engine->>Engine: 初始化上下文 Engine->>Step: 添加步骤 Step->>Step: 设置依赖条件 Client->>Engine: 启动工作流 Engine->>Engine: 检查步骤状态 loop 每个步骤 Engine->>Step: 检查执行条件 alt 条件满足 Step->>Agent: 调用智能体 Agent->>State: 更新状态 Agent-->>Step: 返回结果 Step-->>Engine: 步骤完成 else 条件不满足 Step-->>Engine: 等待依赖 end end Engine->>Engine: 更新工作流状态 Engine-->>Client: 返回结果

🎯 设计特点

  • 状态驱动: 每个步骤都有明确的状态（PENDING → RUNNING → COMPLETED/FAILED）
  • 条件执行: 基于前置条件和依赖关系智能调度步骤执行
  • 上下文共享: 通过AgentState实现智能体间的信息共享
  • 错误处理: 完善的异常处理和重试机制
  • 可扩展性: 支持自定义步骤类型和智能体
